# 🤝 Contributing to Slimefall

Thanks for helping! 💚

1. Fork & clone, then `npm run dev` (no install needed for the web game).
2. Make your change. Content lives in `www/src/data/`, the engine in `www/src/game/`.
3. Run the bot: `npm run sim`. It must not crash, and balance shouldn't swing wildly.
4. Open a PR, with a screenshot or GIF if it's visual 📸.

**Style:** small modules, comments that explain *why*, no runtime dependencies, keep it fast on low-end phones.
**Originality:** all art, names and mechanics must be original. Don't copy assets from other games.
